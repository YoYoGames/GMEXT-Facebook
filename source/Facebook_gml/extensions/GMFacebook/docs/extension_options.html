Extension Options

Open the GMFacebook extension's options from the Asset Browser (double-click the extension, or right-click it and choose Properties) to fill in your Meta app details. All three values come from the Meta developer dashboard - see Setup for how to get there, and Meta App Dashboard for Meta's own documentation on the dashboard itself.

App Data

Option Required Where to find it What it does
App ID Yes Settings -> Basic -> App ID Identifies your app to Meta. Written into the Android string resources and the iOS plist, and used to build the fb<AppID> URL scheme that Meta's login flow returns to. fb_initialize fails if this is empty.
Display Name Yes Settings -> Basic -> Display Name The app name Meta shows the player on the login and share screens. Written into the iOS plist.
Client Token Yes Settings -> Advanced -> Security -> Client Token The public client credential Meta's SDK authenticates with. fb_initialize fails if this is empty.

Warning

Do not put your App Secret in here, or anywhere else in the project. It is a server-side credential and anything shipped inside a game can be extracted from it.

Required project settings

These are not extension options, but the extension will not build or run without them.

Android

In the General section of the Android Game Options:

Setting Minimum
Minimum SDK 21

Meta's facebook-android-sdk 18.x does not support anything older.

iOS

In the iOS Game Options:

Setting Minimum
Minimum iOS Version 12.0

GameMaker's default is lower than this, and the failure is not obvious - pod install refuses the Facebook pods outright, so the build dies during the CocoaPods step rather than telling you the deployment target is wrong. Set it before your first iOS build.

Building for iOS also requires CocoaPods to be installed on the Mac - installation guide.

What the extension configures for you

You do not need to edit any of the injection boxes in the extension's platform settings. From the three options above, the extension writes everything Meta's SDKs require at build time:

Android

  • The Gradle dependency on com.facebook.android:facebook-android-sdk.
  • The facebook_app_id, facebook_client_token and fb_login_protocol_scheme string resources.
  • The com.facebook.sdk.ApplicationId and com.facebook.sdk.ClientToken manifest metadata.
  • The FacebookActivity and CustomTabActivity declarations, including the browser intent filter that lets Meta's login flow return to your game.

iOS

  • The FacebookAppID, FacebookClientToken and FacebookDisplayName plist keys.
  • The fb<AppID> URL scheme, and the fbapi / fb-messenger-share-api query schemes that let the SDK hand off to the Facebook and Messenger apps when they are installed.
  • The CocoaPods dependencies on FBSDKCoreKit, FBSDKLoginKit and FBSDKShareKit.

Export targets

The extension only has Android and iOS implementations. Leave its other export targets disabled - on any other platform every function returns a default value and nothing reaches Meta, so guard your calls with an os_type check if your project also builds elsewhere.
