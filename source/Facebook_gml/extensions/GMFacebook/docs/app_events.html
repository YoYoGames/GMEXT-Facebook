fb_send_event

Logs one of Meta's standard App Events, which is what makes it show up in the Events Manager's built-in reports and become usable for ad optimisation and audience building. For anything Meta has no standard name for, use fb_send_custom_event instead.

Events are batched by the SDK and uploaded on its own schedule - see fb_flush_events if you need one sent immediately. Nothing is returned: Meta's own logging API has no result, and an invalid request (an unrecognised event, or a non-finite value) is dropped with a warning in the native log rather than reported back.


Syntax:

fb_send_event(event, value, parameters)
Argument Type Description
event FacebookAppEvent Which standard event to log.
value Real The numeric value to associate with the event - typically a currency amount, or
0 where the event has no natural value.
parameters Array of FacebookEventParameterValue The standard parameters to attach.
Pass an empty array for none.


Returns:

N/A


Example:

var _content_id = new FacebookEventParameterValue();
_content_id.key = FacebookAppEventParameter.ContentId;
_content_id.string_value = "wishlist_item_001";
_content_id.number_value = 0;
_content_id.use_number = false;

var _num_items = new FacebookEventParameterValue();
_num_items.key = FacebookAppEventParameter.NumItems;
_num_items.string_value = "";
_num_items.number_value = 1;
_num_items.use_number = true;

fb_send_event(FacebookAppEvent.AddedToWishlist, 123.00, [_content_id, _num_items]);

fb_send_custom_event

Logs an App Event under a name of your own, for the things Meta has no standard event for - a level restart, a tutorial skip, a shop screen opened. Custom events still appear in the Events Manager and can still be used to build audiences; they just do not feed Meta's built-in optimisation the way the standard events in fb_send_event do.

As with the standard events, nothing is returned and an invalid request (an empty name, a non-finite value) is dropped with a warning in the native log.

Note

Keep the set of event names small and stable. Meta caps how many distinct custom event names an app can report, and a name built from a variable will burn through that cap - put the variable part in a parameter instead.


Syntax:

fb_send_custom_event(event_name, value, parameters)
Argument Type Description
event_name String The event name. Trimmed of surrounding whitespace before it is sent.
value Real The numeric value to associate with the event, or 0 if it has none.
parameters Array of FacebookNamedValue The parameters to attach, with names of your
own choosing. Pass an empty array for none.


Returns:

N/A


Example:

var _level = new FacebookNamedValue();
_level.name = "level_name";
_level.string_value = "forest_02";
_level.number_value = 0;
_level.use_number = false;

fb_send_custom_event("level_restarted", 1, [_level]);

fb_send_purchase

Logs a purchase. This is the event Meta's purchase reporting and value-optimised ad campaigns are built on, so it goes through Meta's dedicated purchase API rather than being a standard event you would send with fb_send_event.

Nothing is returned. A negative or non-finite amount, or a currency that is not exactly three letters, is dropped with a warning in the native log.

Warning

This only reports a purchase - it does not verify one. Call it after your store of record (Google Play Billing, StoreKit) has confirmed the transaction, never before.


Syntax:

fb_send_purchase(amount, currency, parameters)
Argument Type Description
amount Real The amount paid, in the units of currency (so 4.99, not 499).
currency String The ISO 4217 currency code, e.g. "USD". Case is not significant.
parameters Array of FacebookNamedValue Extra parameters to attach, such as the
product identifier. Pass an empty array for none.


Returns:

N/A


Example:

var _product = new FacebookNamedValue();
_product.name = "product_id";
_product.string_value = "com.example.game.gems_100";
_product.number_value = 0;
_product.use_number = false;

fb_send_purchase(4.99, "USD", [_product]);

fb_flush_events

Sends every queued App Event to Meta right now, instead of waiting for the SDK's own upload schedule.

You normally should not call this. The SDK batches deliberately, to save the player's battery and data, and flushing after every event throws that away. It is useful while testing (so an event shows up in the Events Manager within seconds rather than minutes) and just before a point where the app may be killed.


Syntax:

fb_flush_events()


Returns:

N/A

fb_set_event_user_id

Attaches your own user identifier to every App Event logged from this point on, so events from the same player can be tied together across devices and reinstalls. The value persists across app launches until it is changed or cleared with fb_clear_event_user_id.

Passing an empty string clears the identifier, exactly as fb_clear_event_user_id does.

Warning

Use an opaque identifier of your own. Never pass an email address, a phone number, a name, or anything else that identifies a real person - Meta's terms forbid it.


Syntax:

fb_set_event_user_id(user_id)
Argument Type Description
user_id String Your own identifier for the current player.


Returns:

N/A

fb_get_event_user_id

Returns the identifier previously set with fb_set_event_user_id.


Syntax:

fb_get_event_user_id()


Returns:

String

The current App Events user ID, or an empty string if none is set.

fb_clear_event_user_id

Clears the identifier set with fb_set_event_user_id, so subsequent App Events carry no user ID. Call this when the player signs out of your own account system.


Syntax:

fb_clear_event_user_id()


Returns:

N/A

FacebookAppEvent

Meta's standard App Events, as accepted by fb_send_event. Using a standard event rather than a custom one is what lets Meta's built-in reporting and ad optimisation understand what happened. Full definitions are in Meta's App Events reference.

These constants are referenced by the following functions:

  • fb_send_event


Member Description
AchievedLevel The player reached a new level.
AddedPaymentInfo The player entered payment details.
AddedToCart The player added an item to a cart.
AddedToWishlist The player added an item to a wishlist.
CompletedRegistration The player finished creating an account.
CompletedTutorial The player finished the tutorial.
InitiatedCheckout The player started a checkout flow.
Rated The player rated something. Pair with MaxRatingValue.
Searched The player ran a search. Pair with SearchString.
SpentCredits The player spent in-game currency.
UnlockedAchievement The player unlocked an achievement.
ViewedContent The player viewed a piece of content.
Contact The player contacted your business.
CustomizeProduct The player customised a product.
Donate The player made a donation.
FindLocation The player looked up a physical location.
Schedule The player booked an appointment.
StartTrial The player started a free trial.
SubmitApplication The player submitted an application.
Subscribe The player started a paid subscription.
AdImpression An ad was shown to the player.
AdClick The player clicked an ad.

FacebookAppEventParameter

Meta's standard App Event parameter names, used as the key of a FacebookEventParameterValue. A parameter sent under one of these names is understood by the Events Manager's breakdowns; anything else needs a custom event (fb_send_custom_event) with a free-text name.

These constants are referenced by the following structs:

  • FacebookEventParameterValue


Member Description
Content A description of the content involved, often a JSON string.
AdType The type of ad, for the AdImpression and AdClick events.
ContentId The identifier of the content or product involved.
ContentType The category of the content or product involved.
Currency The ISO 4217 currency code the event's value is expressed in.
Description A free-text description of the event.
Level The level the player reached, for the AchievedLevel event.
MaxRatingValue The top of the rating scale, for the Rated event. Numeric.
NumItems How many items the event covers. Numeric.
PaymentInfoAvailable Whether payment details are already on file. Numeric, 1 or 0.
RegistrationMethod How the player registered, e.g. "Facebook" or "Email".
SearchString What the player searched for, for the Searched event.
Success Whether the action succeeded. Numeric, 1 or 0.
OrderId The order identifier for a transaction.

FacebookEventParameterValue

A single parameter attached to a standard App Event sent with fb_send_event. It is the same shape as FacebookNamedValue except that the name is not free text - it is a FacebookAppEventParameter value, so the parameter lands on one of Meta's own recognised parameter names and is usable in the Events Manager's breakdowns.

The struct carries both a string and a number slot, and use_number selects which one is actually sent. This is a generated extension record, so it is created with an empty constructor and every field is assigned afterwards.

This struct is referenced by the following functions:

  • fb_send_event


Member Type Description
key FacebookAppEventParameter Which standard parameter this value is for.
string_value String The value to send when use_number is false.
number_value Real The value to send when use_number is true.
use_number Boolean Whether to send number_value (true) or string_value (false).
